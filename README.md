# ⚽ Catálogo de Times

Aplicação web para visualização e consulta de detalhes de times de futebol, desenvolvida com Node.js, Express e EJS.

## 🚀 Tecnologias Utilizadas

- **Node.js** — Ambiente de execução JavaScript no servidor
- **Express** — Framework web para rotas e middleware
- **EJS** — Motor de templates para renderização de HTML dinâmico
- **CSS3 / HTML5** — Estilização e estruturação visual

## 📌 Funcionalidades

- Listagem de times cadastrados
- Exibição de informações e detalhes específicos de cada time
- Página de erro customizada para rotas não encontradas (404)
